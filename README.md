# PTSolns IDE
<img src="/Logo/PTSolns IDE Logo Partial with Slogan.jpg" height="150" align="right" />

This repository contains the source code of the _PTSolns IDE_. Our goal in developing and provding _PTSolns IDE_:

- __Free__ to download, __No__ subscriptions, __No__ fees
- __No__ sign-ups, __No__ sign-ins, __No__ cloud
- Open-source & Community driven :heart:

__Just write code and program your board.__

Some notable features include:

- Compatible with many common boards (AVR, RPI, Espressif, etc)
- Large collection of 3rd party libraries (updated daily)
- Many example sketches installed by default
- Inherent CH340 driver support from within the application

We always welcome feedback and suggestions. Please [contact us](https://ptsolns.com/pages/contact) directly.

## Download
Download the latest release here [_PTSolns IDE_](https://ptsolns.com/ide).

## Installation Support
As with any desktop application, there may be the occational hiccup. We are constantly updating and revising our [PTSolns IDE Help Page](https://ptsolns.com/ide-help) to gather any user issues and to make installing _PTSolns IDE_ as easy as possible.

If you have found a potential bug or installation issue, please let us know by [submitting a new issue](https://github.com/PTSolns/PTSolns-IDE/issues).

## CH340 Driver Support
_PTSolns IDE_ inherently supports the common and popular CH340 driver. To accomplish this we have wrapped our own CH340 driver installation tool, which can be initiated directly from within the application. For full details please see [PTSolns.com/CH340](https://ptsolns.com/ch340)

## Bugs? :bug:
Have you found a bug? Please let us know by [submitting a new issue](https://github.com/PTSolns/PTSolns-IDE/issues).

## Future Development
This is just the beginning! We have a lot of plans to expand and improve _PTSolns IDE_. Our growth is community driven and depends on demand. Some of our current plans for future development include:
- Circuit simulation
- Support for PIC boards
- macOS autoupdater (currently only for Windows OS)
- Bring back support for running IDE on RPi
- And so much more. Users are encouraged to submit their own suggestions by [contacting us](https://ptsolns.com/pages/contact).
